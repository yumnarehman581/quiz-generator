# Quiz Generator

A beginner-friendly Python quiz generator with randomized questions, multiple-choice answers, score tracking, and percentage calculation.

## Features

- Randomized quiz questions
- Multiple-choice answers
- Automatic answer checking
- Score calculation
- Percentage calculation
- Performance-based feedback

## How to Run

1. Make sure Python is installed.
2. Open the project in VS Code.
3. Run main.py.
